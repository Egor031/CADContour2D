B1/P1 — FIXED AND INDEPENDENTLY VERIFIED

Production: density_builder.cpp:155, 416–422, 552–562, 581–582.
Group содержит expected CRC32 точных LE32 event bytes. CRC write chunk вычисляется
до transfer seam и сохраняется после exact successful write. При чтении CRC
накапливается независимо по фактически полученному buffer. Проверка после
length/index/count/EOF precedes tile-copy/ingest группы. Несовпадение возвращает
InconsistentEvents/Accumulation с group context, success/pending не выходит.

Независимый прежний сценарий [(0,0),(1,0),(2,0)], cell=1, literal [1,2]: normal
build корректен, in-range bitflip больше не даёт [0,3]/success, а отклоняется.
Проверка расширена до 40005 measurements / 160020 spool bytes, нескольких append
и read chunks, обеих tileSide 256/512 и capacities 1/31/20000. Обнаружены:
first/last/offset65536 bitflip, same-length replacement, перестановка stream даже
при неизменных spatial counts, pre-write и post-read buffer mutations. Для каждой
такой порчи CRC mismatch возникает до D ingest повреждённой группы.

Short read/write сохраняют отдельную ScratchIO причину; truncate/extra bytes и
invalid indices не подменены checksum handling. Source и предыдущий законченный D
проверены SHA-256/буквальными counts и сохранены; failed build оставляет только
собственные исходные fixtures, без result/spools. Это operation-local injections,
не physical device fault validation. CRC — контроль случайного повреждения,
не криптографическая аутентификация.

Собственные integrity/resource probes: 134 scenarios PASS / 0 FAIL в Debug и
столько же в Release. Код/точные команды/логи: resources/resource-review.md,
resources/spool_probe.cpp, resources/probe-debug.log, resources/probe-release.log.
