D. ВЫВОДЫ ПО КОНТРАКТАМ

Admission/snapshot/applicability — подтверждены. Нет admission без source/
receiver; immutable snapshot удерживает physical binding, исходные cell/
profile/resources, runtime/context и captured receiver. Worker не читает
mutable controller/state/QML. Paths fully qualified, CWD independence
проверена. Future-cell не отзывает Build; исключение moveHistory проверяет
именно SetCellCommand, соседние operation kinds не получили это исключение.
Настоящая invalidation и ABA не восстанавливают authority.
Refs: project_controller.cpp:329–381,399–436,553–650.

Typed transport/publication — подтверждены. Unique product и kind сверяются
в worker, descriptor соответствует actual PendingDataset/snapshot, включая
id/source/count/CompletePointCache/binary64 bits/Mapping/tileSide/path/statistics.
Ready не переносит file guards. Fallible preparation даёт failed Ready с
сохранённым worker cleanup; все Ready ветви получают решение. Production
gate: initial→prepare вне mutex→candidate validation→final→noexcept commit
вместе с Accept под decision mutex. Notifications и destruction после него.
GUI не делает Mapping factory/full Reader/hash; существующий bounded
diagnostic log не следует путать с отсутствием вообще любого GUI I/O.
Требования к noexcept commit обеспечиваются typed API contract и harness;
их реализацию новым production catalogue предстоит проверить в 06.4.
Refs: density_operation.cpp:172–224,237–304;
operation_runner.cpp:96–121,195–268;
project_controller.cpp:886–949; density_build_types.h:35–54.

Ownership/lease/cancellation/native completion — подтверждены. Borrowed lease
защищает D во время reentrant prepare; controller не ждёт worker под lease.
Accept необратим, session/receiver могут исчезнуть до handoff без удаления D.
Worker делает retain/releaseToOwner; Discard удаляет Pending прежде directory,
вне mutex и без recursive удаления foreign children. Locked cleanup остаётся
secondary diagnostic. Busy требует cleanup + native completion + Qt join,
а Ready/Builder Complete ещё не применение. Нет terminate/очереди/retry.
Destructor/native observation fail-safe и соседние guards сохранены.
Refs: density_operation.cpp:197–234; operation_runner.cpp:275–365,444–548;
project_controller.cpp:951–1041.

Progress/errors/resources — подтверждены в проверенной области. Fixed-size
latest-value mailbox, phase-local counters и unknown totals; terminal success
не публикуется через Finish. Noexcept bridges ловят exception и кооперативно
останавливают builder. Structured BuildError и первичная ошибка сохраняются;
cleanup отдельно. Retained diagnostics используют shared lifetime без stack/
controller pointers и не меняют следующую операцию поздним сообщением.
Ceilings передаются builder без увеличения. Default 32/8MiB working/metadata,
reader 1 MiB и component reservations — accounting policy, не process/RAM cap.
Directories/paths, bounded transport/diagnostics, candidate storage и Qt/native
runner overhead указаны отдельно в контрактах/отчёте; будущий catalogue storage
проверяется в 06.4. Physical free space/allocator overhead не гарантируются.
Refs: density_operation.cpp:131–168; operation_runner.cpp:40–49;
density_build_types.h; density_builder.h:resource policy.
