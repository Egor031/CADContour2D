ПРОВЕРЕННЫЕ КОНТРАКТЫ

- Явные LE widths, binary64 bit_cast, signed zero, UUID/source/build contract.
  Header/footer CRC и reserved, checked section arithmetic, contiguous payloads,
  точный размер файла и completion; ошибки до allocation/seek/conversion.
- Mapping восстанавливается factory с явной ValidationPolicy/callback;
  origin bits, original bounds, dimensions и convention сверяются. FP-контракт
  06.1 не обходится. Mapping work O(width+height) остаётся отдельным ограничением.
- Точные u32/u64, канонический выбор по maximum, partial edges, X-fast/Y-up,
  checked totals и CompletePointCache total == declared measurements.
- Open проверяет весь sparse structural index O(T), без payload и без RAM-array
  descriptors. Только затем missing key означает ноль. ReadTile проверяет нужный
  payload; fullValidate/physical iteration — все физические tiles. Повреждение
  другого payload может оставаться неизвестным при selective read: это объявленная
  граница, а не подтверждение полной целостности Open.
- Строгий один завершённый zlib stream: exact output и consumed input, decoded CRC,
  max/total, canonical encoding/zero omission; dictionary/trailing/concatenation,
  truncation и oversized output отвергаются, частичный Tile не возвращается.
- Arbitrary ingest, включая zero submissions; bounded initial runs <=4096 Entry,
  две descriptor tapes и bounded two-way merge, canonical payload/index order,
  duplicate zero/nonzero rejection. Нет full raster или unlimited descriptor list.
- Buffer reserve покрывает одновременно decoded/packed/compressed +64 KiB I/O;
  custom zalloc учитывает charged headers и отказывает до allocation. Sort array
  освобождается до merge/copy/readback. Caller-retained results/borrowed buffers
  исключены явно; fixed Qt/allocator/OS overhead не объявлен memory cap.
- Scratch/output/combined logical bytes проверяются до роста файлов; обе tapes
  учтены одновременно. Writer требует5 dataset handles с readback, Reader1.
  Work writer накопителен с остатком для Open/full readback; mapping budget отдельный.
  Ноль не означает unlimited. Cancellation bounded checkpoints, не wall-clock deadline.
- Single-use/terminal failures, reentry guard, independent reader handles, borrowed
  callback lifetimes и diagnostic context до destruction writer/pending согласованы.
  Flush и полный readback до non-overwriting rename; PendingDataset RAII discard и
  releaseToOwner. Cleanup diagnostic не заменяет primary error. Новый discard не
  меняет прежние методы/поля/поведение StagedFile и не используется Point Cache.
